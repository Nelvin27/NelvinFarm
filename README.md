# Clover Patch 3D

A voxel-style farming game for Godot 4.

- **Clover-Patch-3D** is the game. Import its `project.godot` and press **F5**.
- **tools/audio** synthesizes the music and sound effects.
- **tools/world** builds the valley map. `build_world.py` lays out the town in code and writes `Clover-Patch-3D/world/clover_valley.json`; companion Godot scripts check and preview it. See [AGENTS.md](AGENTS.md).
