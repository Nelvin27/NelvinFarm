# NelvinFarm

Clover Patch 3D is a voxel farming game with a separate Godot World Builder. The complete editable source for both projects is in `Clover-Patch-Git.bundle`.

## Continue on another computer

1. Open `Clover-Patch-Git.bundle` in GitHub and choose **Download raw file**.
2. In the folder where you downloaded it, run:

   ```sh
   git clone Clover-Patch-Git.bundle Clover-Patch
   ```

3. In Godot 4, import `Clover-Patch/Clover-Patch-3D/project.godot` and press **F5** to play.
4. To edit the valley, import `Clover-Patch/Clover-Patch-World-Builder/project.godot` separately and press **F5**. The builder opens the sibling game's world layout. Save your changes and restart the game to test them.

The cloned projects each have a README with controls and development notes.
