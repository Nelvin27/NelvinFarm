# Clover Patch 3D

A voxel-style farming game and its standalone World Builder for Godot 4.

- **Clover-Patch-3D** is the game. Import its `project.godot` and press **F5**.
- **Clover-Patch-World-Builder** is the developer tool. Import its `project.godot` separately and press **F5**. It opens the sibling game's `world/clover_valley.json`. Save changes and restart the game to test them.

Keep both project folders side by side. Each project has its own README with controls and development notes.
